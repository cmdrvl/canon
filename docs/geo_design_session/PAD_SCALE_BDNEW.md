# bd-3sot - PAD At Scale

Agent: PinkGorge.

Access path: Loom only via `cmdrvl-cli` against tenant `salt`; all cited measurements
come from `tool_responses[*].structuredContent` returned by `--raw`.

Data release: PAD current release `26B`, `RELEASE_DT = 2026-05-01`.

## Executive Result

PAD replaces the Appendix E naive address baseline, but it does not behave like a
single-answer exact address string. It is a high-coverage candidate generator with
honest fan-out.

| Measurement | Result |
|---|---:|
| Appendix E naive MapPLUTO primary-address exact match | 1,522 / 5,269 = 28.89% |
| R1 PAD range-aware borough-scoped match | 3,930 / 5,269 = 74.59% |
| R1 PAD unique-BBL keys | 2,337 / 5,269 = 44.35% |
| R1 PAD multi-BBL keys | 1,593 / 5,269 = 30.23% |
| R1 PAD unresolved keys | 1,339 / 5,269 = 25.41% |
| R2 K.2 MapPLUTO-primary strict street presence | 420 / 4,046 = 10.38% |
| R2 PAD/SND strict street presence | 4,005 / 4,046 = 98.99% |
| R3 PAD current BBL universe | 874,168 BBLs |
| R3 mean computed address rows per BBL | 1.517 |
| R3 mean nonzero BINs per BBL | 1.264 |

Design consequence: PAD should be the replacement address-channel baseline and
the lot-side street universe. It should not be collapsed into a unary address
resolver. The product needs the multi-BBL domain because 30.23% of the CMBS
address-county keys that PAD sees resolve to more than one BBL.

## R1 - PAD Resolution At Scale

Predicate:

- Universe: distinct raw `(PROPERTY_ADDRESS, COUNTY_FIPS)` keys in the five NYC
  counties from `WRGL_EDGAR_CMBS_GEOCODES__STRUCTURED`.
- Tier: if a raw key has one distinct `ACCURACY_TYPE`, use it; otherwise `mixed`.
- Borough mapping: `36061 -> 1`, `36005 -> 2`, `36047 -> 3`, `36081 -> 4`,
  `36085 -> 5`.
- Street input: geocoder `STREET` only. There is no raw-address street fallback;
  this is why `place` has zero parsed-street keys.
- Street normalizer: token-table normalizer from Appendix K.2, plus `CIRCLE`,
  `EXPRESSWAY`, and `PLAZA`; directionals, suffixes, spelled ordinals 1-12, and
  numeric ordinal suffixes are normalized.
- Number input: geocoder `NUMBER` plus the leading number/range token from raw
  `PROPERTY_ADDRESS`.
- Queens hyphenates: a Queens `NN-NN` house number is collapsed to one integer
  by stripping non-digits, e.g. `130-50 -> 13050`.
- Other hyphen, slash, ampersand, and `AND` forms are treated as low/high number
  ranges.
- PAD edge: current PAD address row, same borough, equal normalized street, and
  range overlap: `input_lo <= pad_high AND input_hi >= pad_low`.
- Reported fan-out is distinct PAD `BBL_KEY` count per raw key.

## R2 - SND Street-Normalization Replay

Predicate:

- Universe: K.2 distinct geocode point grain, `LATITUDE, LONGITUDE`, in the five
  NYC counties.
- Same centroid-r9+k1 tile semantics as K.2:
  `H3_GRID_DISK(H3_POINT_TO_CELL_STRING(ST_POINT(lon,lat),9),1)`.
- Query-side street: geocoder `STREET`, normalized with the same K.2 normalizer.
- Lot-side street universe: PAD direct normalized street plus SND variants keyed
  through PAD address rows:
  `STREET_NAME_NORMALIZED` and `FULL_STREET_NAME_NORMALIZED` by
  `STREET_LOCAL_GROUP_CODE`, and `STREET_NAME_20` by `STREET_CODE_BORO`.
- To avoid timeout, the successful full-universe query pushed the normalized
  input street set before joining PAD/SND BBL streets to MapPLUTO tile parcels.

### R1 Main

```sql
WITH scope_rows AS (
  SELECT PROPERTY_ADDRESS, COUNTY_FIPS, ACCURACY_TYPE, NUMBER, STREET
  FROM EDGAR_DB.DBT_WRANGLING_EDGAR.WRGL_EDGAR_CMBS_GEOCODES__STRUCTURED
  WHERE COUNTY_FIPS IN ('36005','36047','36061','36081','36085')
    AND PROPERTY_ADDRESS IS NOT NULL
), ak AS (
  SELECT PROPERTY_ADDRESS, COUNTY_FIPS,
    CASE COUNTY_FIPS WHEN '36005' THEN 2 WHEN '36047' THEN 3 WHEN '36061' THEN 1 WHEN '36081' THEN 4 WHEN '36085' THEN 5 END AS BORO,
    CASE WHEN COUNT(DISTINCT ACCURACY_TYPE)=1 THEN MIN(ACCURACY_TYPE) ELSE 'mixed' END AS ACCURACY_TYPE
  FROM scope_rows GROUP BY PROPERTY_ADDRESS, COUNTY_FIPS
), raw_nums AS (
  SELECT PROPERTY_ADDRESS, COUNTY_FIPS, NUMBER AS RAW_NUM FROM scope_rows WHERE NUMBER IS NOT NULL
  UNION ALL
  SELECT PROPERTY_ADDRESS, COUNTY_FIPS,
    REGEXP_SUBSTR(PROPERTY_ADDRESS,'^[[:space:]]*[0-9]+[A-Z]?[[:space:]]*((-|/|&|AND)[[:space:]]*[0-9]+[A-Z]?)?') AS RAW_NUM
  FROM ak
), nums AS (
  SELECT DISTINCT PROPERTY_ADDRESS, COUNTY_FIPS,
    CASE WHEN COUNTY_FIPS='36081' AND REGEXP_LIKE(REGEXP_REPLACE(UPPER(RAW_NUM),'[^0-9A-Z-]+',''),'^[0-9]+-[0-9]+[A-Z]?$')
      THEN TRY_TO_NUMBER(REGEXP_REPLACE(RAW_NUM,'[^0-9]+',''))
      ELSE TRY_TO_NUMBER(REGEXP_SUBSTR(RAW_NUM,'[0-9]+',1,1)) END AS LO_NUM,
    CASE WHEN COUNTY_FIPS='36081' AND REGEXP_LIKE(REGEXP_REPLACE(UPPER(RAW_NUM),'[^0-9A-Z-]+',''),'^[0-9]+-[0-9]+[A-Z]?$')
      THEN TRY_TO_NUMBER(REGEXP_REPLACE(RAW_NUM,'[^0-9]+',''))
      ELSE COALESCE(TRY_TO_NUMBER(REGEXP_SUBSTR(RAW_NUM,'[0-9]+',1,2)), TRY_TO_NUMBER(REGEXP_SUBSTR(RAW_NUM,'[0-9]+',1,1))) END AS HI_NUM
  FROM raw_nums
  WHERE RAW_NUM IS NOT NULL
), street_src AS (
  SELECT 'i' SRC, PROPERTY_ADDRESS, COUNTY_FIPS, CAST(NULL AS NUMBER) BORO, CAST(NULL AS TEXT) BBL_KEY, CAST(NULL AS TEXT) BIN_KEY, CAST(NULL AS NUMBER) LOW_INT, CAST(NULL AS NUMBER) HIGH_INT, STREET AS RAW_STREET
  FROM scope_rows WHERE STREET IS NOT NULL
  UNION ALL
  SELECT 'p', CAST(NULL AS TEXT), CAST(NULL AS TEXT), BORO, BBL_KEY, BIN_KEY, LOW_HOUSE_NUMBER_INT, COALESCE(HIGH_HOUSE_NUMBER_INT,LOW_HOUSE_NUMBER_INT), STREET_NAME_NORMALIZED
  FROM EDGAR_DB.SOURCE.NYC_DCP_PAD_ADDRESS_HOT
  WHERE IS_CURRENT_RELEASE=TRUE AND BBL_KEY IS NOT NULL AND LOW_HOUSE_NUMBER_INT IS NOT NULL AND STREET_NAME_NORMALIZED IS NOT NULL
), tok AS (
  SELECT SRC, PROPERTY_ADDRESS, COUNTY_FIPS, BORO, BBL_KEY, BIN_KEY, LOW_INT, HIGH_INT, RAW_STREET, t.index,
    DECODE(t.value,'NORTH','N','SOUTH','S','EAST','E','WEST','W','STREET','ST','AVENUE','AVE','ROAD','RD','BOULEVARD','BLVD','PLACE','PL','DRIVE','DR','LANE','LN','COURT','CT','PARKWAY','PKWY','HIGHWAY','HWY','TERRACE','TER','CIRCLE','CIR','EXPRESSWAY','EXPY','PLAZA','PLZ','FIRST','1','SECOND','2','THIRD','3','FOURTH','4','FIFTH','5','SIXTH','6','SEVENTH','7','EIGHTH','8','NINTH','9','TENTH','10','ELEVENTH','11','TWELFTH','12',REGEXP_REPLACE(t.value,'^([0-9]+)(ST|ND|RD|TH)$','\\1')) AS V
  FROM street_src, LATERAL SPLIT_TO_TABLE(REGEXP_REPLACE(UPPER(COALESCE(RAW_STREET,'')),'[^A-Z0-9]+',' '),' ') t
  WHERE t.value <> ''
), st AS (
  SELECT SRC, PROPERTY_ADDRESS, COUNTY_FIPS, BORO, BBL_KEY, BIN_KEY, LOW_INT, HIGH_INT, RAW_STREET,
    LISTAGG(V,' ') WITHIN GROUP(ORDER BY index) AS STREET_NORM
  FROM tok GROUP BY SRC, PROPERTY_ADDRESS, COUNTY_FIPS, BORO, BBL_KEY, BIN_KEY, LOW_INT, HIGH_INT, RAW_STREET
), i_st AS (SELECT DISTINCT PROPERTY_ADDRESS, COUNTY_FIPS, STREET_NORM FROM st WHERE SRC='i'),
p_st AS (SELECT DISTINCT BORO, BBL_KEY, BIN_KEY, LOW_INT, HIGH_INT, STREET_NORM FROM st WHERE SRC='p'),
pad_edges AS (
  SELECT DISTINCT ak.PROPERTY_ADDRESS, ak.COUNTY_FIPS, p.BBL_KEY
  FROM ak JOIN i_st i ON i.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND i.COUNTY_FIPS=ak.COUNTY_FIPS
  JOIN nums n ON n.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND n.COUNTY_FIPS=ak.COUNTY_FIPS
  JOIN p_st p ON p.BORO=ak.BORO AND p.STREET_NORM=i.STREET_NORM
    AND n.LO_NUM IS NOT NULL AND n.HI_NUM IS NOT NULL
    AND n.LO_NUM <= p.HIGH_INT AND n.HI_NUM >= p.LOW_INT
), pluto_edges AS (
  SELECT DISTINCT ak.PROPERTY_ADDRESS, ak.COUNTY_FIPS, REGEXP_REPLACE(TO_VARCHAR(mp.BBL),'[.]0$','') AS BBL
  FROM ak JOIN EDGAR_DB.SOURCE.NYC_DCP_MAPPLUTO_HOT mp
    ON mp.BOROUGH = CASE ak.BORO WHEN 1 THEN 'MN' WHEN 2 THEN 'BX' WHEN 3 THEN 'BK' WHEN 4 THEN 'QN' WHEN 5 THEN 'SI' END
   AND REGEXP_REPLACE(UPPER(TRIM(mp.ADDRESS)),'[^A-Z0-9]','') = REGEXP_REPLACE(UPPER(TRIM(ak.PROPERTY_ADDRESS)),'[^A-Z0-9]','')
), ks AS (
  SELECT ak.PROPERTY_ADDRESS, ak.COUNTY_FIPS, ak.ACCURACY_TYPE,
    COUNT(DISTINCT i.STREET_NORM) AS INPUT_STREETS,
    COUNT(DISTINCT n.LO_NUM || '-' || n.HI_NUM) AS INPUT_NUMBER_RANGES,
    COUNT(DISTINCT pe.BBL_KEY) AS PAD_BBLS,
    COUNT(DISTINCT ple.BBL) AS PLUTO_BBLS
  FROM ak
  LEFT JOIN i_st i ON i.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND i.COUNTY_FIPS=ak.COUNTY_FIPS
  LEFT JOIN nums n ON n.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND n.COUNTY_FIPS=ak.COUNTY_FIPS
  LEFT JOIN pad_edges pe ON pe.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND pe.COUNTY_FIPS=ak.COUNTY_FIPS
  LEFT JOIN pluto_edges ple ON ple.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND ple.COUNTY_FIPS=ak.COUNTY_FIPS
  GROUP BY ak.PROPERTY_ADDRESS, ak.COUNTY_FIPS, ak.ACCURACY_TYPE
), ag AS (
  SELECT ACCURACY_TYPE, COUNT(*) ADDRESS_COUNTY_KEYS, SUM(IFF(INPUT_STREETS>0,1,0)) PARSED_STREET_KEYS, SUM(IFF(INPUT_NUMBER_RANGES>0,1,0)) PARSED_NUMBER_KEYS,
    SUM(IFF(PAD_BBLS>0,1,0)) PAD_MATCHED_KEYS, SUM(IFF(PAD_BBLS=0,1,0)) PAD_UNRESOLVED_KEYS,
    SUM(IFF(PAD_BBLS=1,1,0)) PAD_UNIQUE_KEYS, SUM(IFF(PAD_BBLS>1,1,0)) PAD_MULTI_BBL_KEYS, SUM(PAD_BBLS) PAD_BBL_EDGES, MAX(PAD_BBLS) MAX_PAD_BBLS_PER_KEY,
    SUM(IFF(PLUTO_BBLS>0,1,0)) PLUTO_NAIVE_MATCHED_KEYS, SUM(IFF(PAD_BBLS>0 AND PLUTO_BBLS=0,1,0)) PAD_ONLY_KEYS
  FROM ks GROUP BY ACCURACY_TYPE
  UNION ALL
  SELECT 'ALL', COUNT(*), SUM(IFF(INPUT_STREETS>0,1,0)), SUM(IFF(INPUT_NUMBER_RANGES>0,1,0)), SUM(IFF(PAD_BBLS>0,1,0)), SUM(IFF(PAD_BBLS=0,1,0)), SUM(IFF(PAD_BBLS=1,1,0)), SUM(IFF(PAD_BBLS>1,1,0)), SUM(PAD_BBLS), MAX(PAD_BBLS), SUM(IFF(PLUTO_BBLS>0,1,0)), SUM(IFF(PAD_BBLS>0 AND PLUTO_BBLS=0,1,0))
  FROM ks
)
SELECT ACCURACY_TYPE, ADDRESS_COUNTY_KEYS, PARSED_STREET_KEYS, PARSED_NUMBER_KEYS, PAD_MATCHED_KEYS,
  ROUND(100.0*PAD_MATCHED_KEYS/NULLIF(ADDRESS_COUNTY_KEYS,0),2) AS PAD_COVERAGE_PCT,
  PAD_UNRESOLVED_KEYS, PAD_UNIQUE_KEYS, PAD_MULTI_BBL_KEYS,
  ROUND(100.0*PAD_MULTI_BBL_KEYS/NULLIF(ADDRESS_COUNTY_KEYS,0),2) AS PAD_MULTI_RATE_PCT,
  PAD_BBL_EDGES, MAX_PAD_BBLS_PER_KEY, PLUTO_NAIVE_MATCHED_KEYS, PAD_ONLY_KEYS
FROM ag ORDER BY IFF(ACCURACY_TYPE='ALL',0,1), ACCURACY_TYPE;
```

```sql
  SELECT ak.PROPERTY_ADDRESS, ak.COUNTY_FIPS, ak.ACCURACY_TYPE,

  SELECT 'ALL_KEYS' SLICE, * FROM ks
  UNION ALL SELECT 'PAD_ONLY_MAPPLUTO_PRIMARY_MISSED', * FROM ks WHERE PAD_BBLS>0 AND PLUTO_BBLS=0
  UNION ALL SELECT 'ANY_HYPHEN_NUMBER', * FROM ks WHERE HAS_HYPHEN=1
  UNION ALL SELECT 'QUEENS_HYPHENATE_NUMBER', * FROM ks WHERE HAS_QN_HYPHEN=1
  UNION ALL SELECT 'NON_QUEENS_HYPHEN_RANGE', * FROM ks WHERE HAS_NON_QN_HYPHEN=1
  UNION ALL SELECT 'SLASH_RANGE_NUMBER', * FROM ks WHERE HAS_SLASH=1
  UNION ALL SELECT 'AMPERSAND_OR_AND_PAIR_NUMBER', * FROM ks WHERE HAS_PAIR_WORD=1
)
SELECT SLICE, COUNT(*) AS KEYS, SUM(IFF(PAD_BBLS>0,1,0)) PAD_MATCHED_KEYS, ROUND(100.0*SUM(IFF(PAD_BBLS>0,1,0))/NULLIF(COUNT(*),0),2) PAD_COVERAGE_PCT,

  SUM(PAD_BBLS) PAD_BBL_EDGES, MAX(PAD_BBLS) MAX_PAD_BBLS_PER_KEY, SUM(IFF(PAD_BBLS>0 AND PLUTO_BBLS=0,1,0)) PAD_ONLY_KEYS
FROM slices GROUP BY SLICE ORDER BY CASE SLICE WHEN 'ALL_KEYS' THEN 0 WHEN 'PAD_ONLY_MAPPLUTO_PRIMARY_MISSED' THEN 1 ELSE 2 END, SLICE;
```

```sql
  WHERE RAW_NUM IS NOT NULL
), street_src AS (
  SELECT 'i' SRC, PROPERTY_ADDRESS, COUNTY_FIPS, CAST(NULL AS NUMBER) BORO, CAST(NULL AS TEXT) BBL_KEY, CAST(NULL AS TEXT) BIN_KEY, CAST(NULL AS NUMBER) LOW_INT, CAST(NULL AS NUMBER) HIGH_INT, STREET AS RAW_STREET
  FROM scope_rows WHERE STREET IS NOT NULL
  UNION ALL
  SELECT 'p', CAST(NULL AS TEXT), CAST(NULL AS TEXT), BORO, BBL_KEY, BIN_KEY, LOW_HOUSE_NUMBER_INT, COALESCE(HIGH_HOUSE_NUMBER_INT,LOW_HOUSE_NUMBER_INT), STREET_NAME_NORMALIZED
  FROM EDGAR_DB.SOURCE.NYC_DCP_PAD_ADDRESS_HOT
  WHERE IS_CURRENT_RELEASE=TRUE AND BBL_KEY IS NOT NULL AND LOW_HOUSE_NUMBER_INT IS NOT NULL AND STREET_NAME_NORMALIZED IS NOT NULL
), tok AS (
  SELECT SRC, PROPERTY_ADDRESS, COUNTY_FIPS, BORO, BBL_KEY, BIN_KEY, LOW_INT, HIGH_INT, RAW_STREET, t.index,
    DECODE(t.value,'NORTH','N','SOUTH','S','EAST','E','WEST','W','STREET','ST','AVENUE','AVE','ROAD','RD','BOULEVARD','BLVD','PLACE','PL','DRIVE','DR','LANE','LN','COURT','CT','PARKWAY','PKWY','HIGHWAY','HWY','TERRACE','TER','CIRCLE','CIR','EXPRESSWAY','EXPY','PLAZA','PLZ','FIRST','1','SECOND','2','THIRD','3','FOURTH','4','FIFTH','5','SIXTH','6','SEVENTH','7','EIGHTH','8','NINTH','9','TENTH','10','ELEVENTH','11','TWELFTH','12',REGEXP_REPLACE(t.value,'^([0-9]+)(ST|ND|RD|TH)$','\\1')) AS V
  FROM street_src, LATERAL SPLIT_TO_TABLE(REGEXP_REPLACE(UPPER(COALESCE(RAW_STREET,'')),'[^A-Z0-9]+',' '),' ') t
  WHERE t.value <> ''
), st AS (
  SELECT SRC, PROPERTY_ADDRESS, COUNTY_FIPS, BORO, BBL_KEY, BIN_KEY, LOW_INT, HIGH_INT, RAW_STREET,
    LISTAGG(V,' ') WITHIN GROUP(ORDER BY index) AS STREET_NORM
  FROM tok GROUP BY SRC, PROPERTY_ADDRESS, COUNTY_FIPS, BORO, BBL_KEY, BIN_KEY, LOW_INT, HIGH_INT, RAW_STREET
), i_st AS (SELECT DISTINCT PROPERTY_ADDRESS, COUNTY_FIPS, STREET_NORM FROM st WHERE SRC='i'),
p_st AS (SELECT DISTINCT BORO, BBL_KEY, BIN_KEY, LOW_INT, HIGH_INT, STREET_NORM FROM st WHERE SRC='p'),
pad_edges AS (
  SELECT DISTINCT ak.PROPERTY_ADDRESS, ak.COUNTY_FIPS, p.BBL_KEY
  FROM ak JOIN i_st i ON i.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND i.COUNTY_FIPS=ak.COUNTY_FIPS
  JOIN nums n ON n.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND n.COUNTY_FIPS=ak.COUNTY_FIPS
  JOIN p_st p ON p.BORO=ak.BORO AND p.STREET_NORM=i.STREET_NORM
    AND n.LO_NUM IS NOT NULL AND n.HI_NUM IS NOT NULL
    AND n.LO_NUM <= p.HIGH_INT AND n.HI_NUM >= p.LOW_INT
), ks AS (
  SELECT ak.PROPERTY_ADDRESS, ak.COUNTY_FIPS, ak.ACCURACY_TYPE, COUNT(DISTINCT pe.BBL_KEY) AS PAD_BBLS
  FROM ak LEFT JOIN pad_edges pe ON pe.PROPERTY_ADDRESS=ak.PROPERTY_ADDRESS AND pe.COUNTY_FIPS=ak.COUNTY_FIPS
  GROUP BY ak.PROPERTY_ADDRESS, ak.COUNTY_FIPS, ak.ACCURACY_TYPE
), dist AS (
  SELECT CASE WHEN PAD_BBLS=0 THEN '0' WHEN PAD_BBLS=1 THEN '1' WHEN PAD_BBLS=2 THEN '2' WHEN PAD_BBLS=3 THEN '3' WHEN PAD_BBLS=4 THEN '4' WHEN PAD_BBLS=5 THEN '5' WHEN PAD_BBLS BETWEEN 6 AND 10 THEN '6-10' WHEN PAD_BBLS BETWEEN 11 AND 25 THEN '11-25' WHEN PAD_BBLS BETWEEN 26 AND 50 THEN '26-50' ELSE '51+' END AS PAD_BBLS_BUCKET, COUNT(*) AS KEYS, MIN(PAD_BBLS) AS MIN_PAD_BBLS, MAX(PAD_BBLS) AS MAX_PAD_BBLS
  FROM ks GROUP BY 1
), summary AS (
  SELECT 'SUMMARY' AS PAD_BBLS_BUCKET, COUNT(*) AS KEYS, MIN(PAD_BBLS) AS MIN_PAD_BBLS, MAX(PAD_BBLS) AS MAX_PAD_BBLS, ROUND(AVG(PAD_BBLS),3) AS AVG_PAD_BBLS, SUM(PAD_BBLS) AS PAD_BBL_EDGES, SUM(IFF(PAD_BBLS>1,1,0)) AS MULTI_KEYS
  FROM ks
)
SELECT PAD_BBLS_BUCKET, KEYS, ROUND(100.0*KEYS/NULLIF(SUM(KEYS) OVER(),0),2) AS PCT_KEYS, MIN_PAD_BBLS, MAX_PAD_BBLS, CAST(NULL AS NUMBER(18,3)) AS AVG_PAD_BBLS, CAST(NULL AS NUMBER(38,0)) AS PAD_BBL_EDGES, CAST(NULL AS NUMBER(38,0)) AS MULTI_KEYS FROM dist
UNION ALL
SELECT PAD_BBLS_BUCKET, KEYS, NULL, MIN_PAD_BBLS, MAX_PAD_BBLS, AVG_PAD_BBLS, PAD_BBL_EDGES, MULTI_KEYS FROM summary
ORDER BY IFF(PAD_BBLS_BUCKET='SUMMARY',0,1), PAD_BBLS_BUCKET;
```
